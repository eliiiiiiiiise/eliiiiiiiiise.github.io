# Featured projects

## Human Rights platform for persons with albinism in Africa

**Tools**: Python - Jupyter Notebooks - pandas - streamlit - transformers - NLP - Gemini API

I designed and developped a platform with publicly available documents on human rights violations against people with albinism in Africa.

- **Data collection and processing**: automated document retrieval (search API), metadata and quote extraction (Large Language Model)
- **Natural language processing**: zero-shot classification for thematic categorisation and named-entity recognition for country extraction.
- **Platform development**: interactive Streamlit platform, evaluating its useability using the System Useability Scale.

[Github of the project](https://github.com/eliiiiiiiiise/masters-project-albinism) - [Dissertation](https://github.com/eliiiiiiiiise/masters-project-albinism/blob/main/Dissertation.pdf)

## Song popularity prediction

**Tools**: R - tidyverse - tidymodels

I built a machine learning model predicting the popularity of a song (on a scale of 1 to 100) using Spotify's audio characteristics data and examined feature importance to identify audio characteristics playing a role in making a song popular.

- **Data cleaning**: exploratory data analysis, data cleaning and imputation of missing values
- **Model building**: implemented an ensemble learning model with feature preprocessing, hyperparameter tuning, and cross-validation
- **Model evaluation**: the model achieved a R-squared of 0.213 on the test dataset, meaning the model explained approximately 21.3% of the variation in track popularity scores on the evaluation dataset.
- **Feature analysis**: Examined feature importance to understand which aspects of a track's sound contributed most to the model's predictions.

[Github of the project](https://github.com/eliiiiiiiiise/song-pop-prediction)

## Gene expression prediction using neural network

**Tools**: Python - Jupyter Notebooks - pandas - torch - scikit-learn

I built a neural network model to predict the gene expression of the lacZ gene, using 45 other gene expressions, exploring the challenges of applying deep learning to biological data.

- **Exploratory data analysis**: exploration of correlations between the 45 features and data pre-processing.
- **Model building**: Iteratively refined the neural network architecture and experimented with regularisation techniques, batch normalisation, dropout different feature selection methods.
- **Model evaluation**: the final model achieved a R-squared on the test dataset close to 0, highlighting the difficulty of predicting the lacZ gene expression using the limited available data.

[Github of the project](https://github.com/eliiiiiiiiise/lacZ-gene-expression)
